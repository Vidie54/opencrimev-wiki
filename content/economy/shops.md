Every shop is on the map. Passive mode is forced inside all of them.

| Shop | Sells |
|---|---|
| **24/7 · LTD · Rob's Liquor** | food, drink, consumables, scratch tickets |
| **Ammu-Nation** | weapons, ammo, armour; Vinewood and Cypress Flats have a [shooting range](wiki:activities/shooting-range) |
| **Clothing** (Discount, Binco, Suburban, Ponsonbys) | clothes — a purchase also [washes a wanted star](wiki:crime/wanted-level#losing-stars) |
| **Barber · Tattoo** | hair and ink; the barber washes a star too |
| **Pawn shop** | *buys* valuables and USB drives |
| **Scrapyard** | *buys* junk and scrap; the crusher takes cars |
| **Vending machines** | eCola, Sprunk, water, snacks — and the weed automat |
| **Showrooms** (car, boat, air) | a rotating stock of models; test drives; see [Owning a vehicle](wiki:vehicles/owning) |
| **Workshops** (LS Customs, Benny's, Beeker's, boat and air) | see [Customs](wiki:vehicles/customs) |

Prices shown in a shop already include the active [discounts](wiki:economy/bonuses-and-events); the server charges the same number.
