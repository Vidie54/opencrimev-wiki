The values below are **your** bindings in game and the defaults on the website. Rebind anything in GTA **Settings → Key Bindings → FiveM**.

| Action | Key |
|---|---|
| Interaction menu | {key:interactionmenu} / middle mouse |
| Inventory | {key:open_inventory} |
| Vehicle controls · MDT (police) | {key:vehiclecontrolsmenu} |
| Lock / unlock vehicle | {key:togglevehiclelock} |
| Map | {key:map} |
| Player board (hold) | {key:+scoreboard} |
| Wiki / help | {key:open_help} |
| Chat · hide chat | {key:openChat} · {key:toggleChatVis} |
| Chat scroll | {key:chatScrollUp} · {key:chatScrollDown} |
| Toggle HUD | {key:+openHud} |
| Interact · enter as passenger | {key:INPUT_PICKUP} |
| Arm a time bomb (driver seat) | {key:INPUT_ATTACK} |
| Sprint · crouch · push-to-talk | GTA defaults |

Contextual prompts ("Press E to …") always name the key you actually have bound.
