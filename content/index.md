**OpenCrimeV** is a fast-paced cops & robbers sandbox on FiveM. No roleplay rules, no whitelist, no waiting: jump in, make money, chase criminals, rob stores, own the city — or keep the peace with a badge.

This wiki is the manual. It is open in game on {key:open_help} (or `/help <page>`) and on the web at {website}, and both read the same pages.

## Start here

- **New?** [First login](wiki:getting-started/first-login) → [Starter pack](wiki:getting-started/starter-pack) → [HUD & keys](wiki:getting-started/hud-and-keys).
- **The rules** are short and they are enforced: [Server Rules](wiki:rules/general).
- **Want to earn?** [Jobs overview](wiki:jobs/overview) for the legal side, [Crime](wiki:crime/wanted-level) for the other one.

## How the numbers work

Prices, payouts and timers on these pages are read from the live server config when the page is drawn — a value like **{money:respawn.deathFee}** is what the server charges right now, not what somebody typed months ago. Key names ({key:INPUT_PICKUP}, {key:interactionmenu}) show *your* binding in game and the default on the website.

> [!NOTE] Beta
> The server is in beta. Characters, money and property may be wiped at the official launch — the same thing the in-game tutorial tells you.

## This wiki is open source

Every page is a Markdown file in a public repository. Found a mistake, or a mechanic nobody has written up yet? Use **Edit this page on GitHub** at the bottom of any page and open a pull request — a maintainer reviews it and it goes live on the website and in game.

Questions, bug reports and ban appeals go to the Discord: {discord}.
